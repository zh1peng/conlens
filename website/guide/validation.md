# 验证记录与适用范围

本页区分数值正确性、软件执行检查和统计校准。测试覆盖率、执行速度和相同种子复现，不能单独证明推断校准。

## 数值与离散边界

`tests/test_scientific_remediation.py` 使用独立 QR OLS 参照检查大偏移原始设计反例：t 约为 7.01717；检查设计变量换单位、中心化、响应缩放、普通组间与交互对比。生产实现使用 SVD，参照使用 QR，避免只验证同一公式的重复调用。

14 条边、集合大小 7、weight=0 的穷举覆盖全部 3,432 个位置：正/负/零 ES 数分别为 1,458 / 1,458 / 516。观测 ES=5/7 时，修复后的方向条件 P 为 92/1459，约 0.06306。标准模式排除无方向零值；positive/negative 模式保留全部合法零分数。空尾部、零尺度及三种评分模式均有测试。

这些证据针对已复现的数值与离散问题，不意味着旧版本默认加权模式普遍产生假阳性。

## 可执行教程与输入政策

同一教学脚本覆盖字符串节点标签、GLM/FL/联合 BH、描述性结果、大小过滤、外部矩阵按 ID 重排、注释集合大小和小规模 bootstrap。受试者对齐测试检查重复、遗漏、排除理由和矩阵大小。退化边保留审计信息并拒绝进入排序；全单例或不改变被检验对比的组内重排会报错。

Bootstrap JSON 往返测试从实际派生种子重算观测参照并逐表核对。种子记录和抽样索引让敏感性分析可追溯，但不会消除有限置换的随机波动。

## 针对性模拟

在仓库根目录执行：

```bash
python -m benchmarks.validate_inference --repetitions 400 --permutations 399 --jobs 4 --bootstrap-draws 40
```

每种情景预先固定 400 个独立数据集、399 次置换，alpha=0.05。400 次重复在真实拒绝率约 5% 时的二项标准误约为 1.1 个百分点，该规模用于发现较大的偏离，不能分辨所有小幅误差。

| 情景 | 数据生成与检验范围 |
| --- | --- |
| independent | 48 名受试者、6 个节点、独立同方差高斯误差 |
| shared_nodes | 叠加共享节点误差，保留跨边相关 |
| within_site | 两站点方差不同，模型加入站点变量，限制站点内残差重排 |
| heteroscedastic_unbalanced | 两组 12/36 人，较小组误差标准差为较大组的 3 倍；作为适用性压力测试 |

每个数据集含组别和年龄两个对比，调整共同干扰变量，检验 3 个大小为 5 的集合（两个不重叠，另一个重叠），共 6 项联合 BH。校准情景的所有被检验系数均为零。报告逐检验未校正拒绝率、P 分位数，以及全局零假设下任一 BH 拒绝的频率（此时等于 FDR），均附 95% Wilson 二项区间，不按单次结果贴“通过”标签。

原始逐次结果、种子、依赖版本、Git HEAD、工作区是否有修改以及实际执行源码 SHA-256 保存在 `benchmarks/results/remediation.json`。未提交修改的实现以源码指纹为准，不能只引用旧 HEAD。

这些模拟在完成整改、尚未将版本标记从 2.2.0 提升为 2.3.0 时执行，原始记录保留当时的真实版本。2.3.0 与该记录对应的统计源码一致，只有 `conlens/_version.py` 的版本标记改变；升级版本号没有重写模拟结果。教程输出和安装包则按 2.3.0 重新生成。

## 排序背景与内层随机性

目标集合的连接数据保持逐元素相同，仅向集合外加入不同强度年龄信号，输出 ES、NES、P/q。这说明集合检验的相对排序性质，不将目标集合内零系数自动记作集合假阳性。

固定 40 组分层 bootstrap 抽样索引及同一观测参照，在 399 和 1,599 次内层置换预算下分别使用三组种子，比较集合稳定性与 core。次数用于量化该例的内层波动，不能视为精确的抽样稳定性估计。不同置换预算应分别建立设置一致的观测与重复结果，标明参照是否改变。

## 证据边界

仓库原有 benchmark 记录的是数值路径一致性和性能，本次没有找到可直接绑定当前源码的历史统计校准结果。新增模拟不覆盖所有节点规模、效应结构、非高斯分布或研究设计。家系、重复测量、混合模型、多层置换、整群 bootstrap 和 PET 原始影像处理仍未由本次验证证明适用。

本地 103 项测试通过，覆盖率 91.19%；Ruff、mypy、wheel/sdist 和网站构建通过。已检查深浅主题与 390×844 手机视口，修复分子教程数学标记和表格溢出，确认该页 24 处数学内容正常生成且页面不被撑宽。软件测试与文档构建纳入 CI。尚未执行独立神经影像研究者首次使用验收，也未将本地执行冒充整个远程跨平台 CI。
