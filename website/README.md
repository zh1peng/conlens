# ConLens documentation

The VitePress source lives in this directory. Chinese is the root locale; the
English locale is scaffolded under `en/` and will be expanded after the Chinese
workflows are finalized.

```bash
cd ..
python -m pip install .
python -m examples.teaching_workflow
python -m examples.teaching_plot
cd website
npm install
npm run docs:dev
npm run docs:build
npm run docs:preview
```

GitHub Pages serves the built site at `https://zh1peng.github.io/conlens/`, so the
VitePress base path is `/conlens/`.

Tutorial code snippets include the tested sources in `examples/`; numeric output is
generated by `examples.teaching_workflow`. CI runs these examples before building the
site. JSON analysis artifacts are local outputs; the compact text and version record
are tracked. Scientific calibration is a separate command in `benchmarks/validate_inference.py`.
