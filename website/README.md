# ConLens documentation

The VitePress source lives in this directory. Chinese is the root locale; the
English locale is scaffolded under `en/` and will be expanded after the Chinese
workflows are finalized.

```bash
npm install
npm run docs:dev
npm run docs:build
npm run docs:preview
```

GitHub Pages serves the built site at `https://zh1peng.github.io/conlens/`, so the
VitePress base path is `/conlens/`.
